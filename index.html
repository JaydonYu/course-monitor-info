PERSONAL COURSEWORK TOOL

Canvas Course Monitor

A personal tool for monitoring changes to coursework using the owner's authorized Canvas access.

What it does

The collector records assignment metadata, deadlines, announcements and submission-status evidence. The Google Drive integration is being configured to keep two derived files up to date: current_changes.json and task_status.json.

The owner can authorize a connected personal assistant, such as ChatGPT, to read those files for coursework summaries and planning. Publishing this information website does not activate or prove that integration.

Why Google Drive access is requested

The integration requests https://www.googleapis.com/auth/drive.file to create and maintain its export files and read them back to check successful updates. This scope is limited to files created by the app or specifically authorized for it; it does not grant blanket access to the owner's Drive.

Intended use

This is a single-owner personal project, not a public sign-up service. It is independent of Canvas, Instructure, Google and any university.

Coursework data and credentials are not published on this website. See the privacy policy for data handling and the terms of use for limitations.
